# Interfaz-Editar-usuario
**Edición de Usuarios** del sistema de gestión marítima **NavOps**


## Estructura del proyecto


Edición de Usuarios Descripción

    Cargar datos del usuario seleccionado al abrir la pantalla.

    Pre-cargar el formulario completo.

    Habilitar edición de todos los campos permitidos.

    Implementar validaciones:

        Campos obligatorios.

        Tipos numéricos.

        Años y fechas.

        Imagen (formato/tamaño).

    Implementar reemplazo de imagen con vista previa.

    Manejar mensajes de éxito o error.

    Botón Cancelar → volver al listado sin cambios.
